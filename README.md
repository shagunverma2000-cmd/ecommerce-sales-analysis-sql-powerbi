# Customer Segmentation & Retention Analysis — SQL

## 📌 Project Overview

This project focuses on analyzing customer behavior using SQL to understand customer segments, purchasing patterns, retention, and overall business performance.

The objective is to transform raw customer and transaction data into meaningful business insights using SQL queries and analytical techniques.

This project demonstrates practical SQL skills required for a **Data Analyst role**, including data cleaning, aggregation, joins, subqueries, window functions, customer segmentation, and business-oriented analysis.

---

## 🎯 Business Objectives

The analysis aims to answer questions such as:

* Who are the most valuable customers?
* How frequently do customers make purchases?
* Which customers are active, inactive, or at risk of becoming inactive?
* What are the purchasing patterns across different customer segments?
* How can customers be segmented based on their behavior?
* What factors are associated with customer retention?
* Which customer groups contribute most to business performance?
* How can SQL-based analysis support customer retention strategies?

## 📊 Analysis Approach

The project follows a structured analytical workflow:

### 1. Data Understanding

The dataset was first explored to understand:

* Number of records
* Number of customers
* Available attributes
* Date ranges
* Missing values
* Duplicate records
* Data consistency

### 2. Data Cleaning

SQL was used to identify and handle:

* Duplicate records
* Missing values
* Invalid or inconsistent data
* Incorrect data formats
* Potential data-quality issues

### 3. Customer-Level Analysis

Customer activity was analyzed using metrics such as:

* Number of transactions
* Total spending
* Average transaction value
* Purchase frequency
* Last purchase date
* Customer activity status

### 4. Customer Segmentation

Customers were grouped based on their purchasing behavior and activity patterns.

The segmentation helps identify groups such as:

* High-value customers
* Frequent customers
* New customers
* Inactive customers
* Potentially at-risk customers

### 5. Retention Analysis

SQL queries were used to understand customer repeat behavior and identify patterns associated with customer retention and inactivity.

### 6. Business Insights

The final analysis converts SQL results into business-oriented insights that can support:

* Customer retention strategies
* Customer targeting
* Marketing campaigns
* Customer re-engagement
* Revenue improvement
